# Contributing

- Read [source ownership](../src/README.md) before editing. Use the [Skyrim save pipeline](save-pipeline.md) when changing search, menu timing, or cosave cleanup.
- Build from this checkout with the pinned dependency and the [documented toolchain](build.md). Run the [regression tests](../tests/README.md) before packaging a candidate.
- Use the [docs index](README.md) to find the guide that owns the behavior you changed.
